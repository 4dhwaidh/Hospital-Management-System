# Hospital Queue Management System

A desktop application for managing hospital patients and organizing a queue using priority-based data structures. The project demonstrates how object-oriented programming and queue management can support patient handling.

- **Patient Management:** Stores and manages patient information.
- **Priority Queue:** Organizes patients according to the priority rules implemented in the application.
- **Doctor Management:** Represents doctor information and related queue operations where implemented.
- **Data Persistence:** Supports saving and loading application data using file handling.
- **Graphical Interface:** Provides a desktop interface using Python Tkinter.

## Technologies Used

Python · Tkinter · Object-Oriented Programming · Priority Queue · File Handling

## Project Workflow

1. Launch the desktop application.
2. Add patient information through the interface.
3. Manage the patient queue using the implemented priority rules.
4. Perform the available patient and doctor management operations.
5. Save or load stored data where supported.

## How to Run

1. Clone or download the repository.
2. Ensure Python 3 is installed.
3. Install any additional dependencies required by the project.
4. Run the main Python application file.

## Project Status

The project implements a graphical hospital queue management application with patient handling, priority-based queue operations, and data persistence.
